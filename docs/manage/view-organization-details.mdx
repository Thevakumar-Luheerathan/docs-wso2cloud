# View organization details

This article shows you how to find your organization's name, handle, and Organization Unit ID. You need the Organization Unit ID when you contact support.

## Prerequisites

- A user account in a WSO2 Cloud organization.

## View your organization's details

1. Sign in to the [WSO2 Cloud console](https://console.cloud.wso2.com).
2. In the sidebar, under **Admin**, select **Organization**.

The page shows the organization's **Name**, **Handle**, and **Organization Unit ID**. To learn what each one is, see [Organizations](./organizations.mdx#how-an-organization-is-identified).
