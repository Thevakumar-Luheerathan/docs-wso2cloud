# Manage service contacts

This article shows you how to choose who WSO2 notifies about your organization. Service contacts receive notices from the WSO2 Cloud team about upcoming cloud changes. Service contacts don't need to be users of the organization.

## Contact categories

| Category | What contacts receive |
| --- | --- |
| **General** | Organization-wide announcements, including maintenance windows and platform changes. |
| **Security** | Security incidents, vulnerability disclosures, and critical patches. |
| **Billing** | Invoices, payment issues, and subscription changes. |

Each category must always have at least one contact.

You can also scope a contact to specific services, so they're only notified about the services that matter to them. A contact with no services selected is notified about all of them.

## Prerequisites

- The **OrganizationAdmin** role in the organization.

## Add a contact

1. Sign in to the [WSO2 Cloud console](https://console.cloud.wso2.com).
2. In the sidebar, under **Admin**, select **Service Contacts**.
3. Select the **General**, **Security**, or **Billing** tab.
4. Select **Add contact**.
5. In **Email address**, enter the contact's email address.
6. In **Categories**, check the categories the contact should receive. The tab you started from is already selected.
7. Optionally, in **Products**, select the services the contact is responsible for. Leave it empty if the contact isn't tied to a specific service.
8. Select **Save**.

## Edit or remove a contact

1. Go to **Admin** > **Service Contacts**, and select the category's tab.
2. To filter the list, use **Search by email** or **Product**.
3. In the contact's row, select the edit icon to change the contact, or the delete icon to remove it.

You can't remove the last contact in a category.
